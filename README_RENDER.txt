AI MEDIA CLEANER — PUBLIC WEBSITE DEPLOYMENT

This package is prepared for Render free web hosting. The owner must create the hosting account and deploy it; the public URL is generated by Render after deployment.

DEPLOY STEPS
1. Create/sign in to a GitHub account: https://github.com
2. Create a new repository named ai-media-cleaner. Choose Public (the source code will be visible).
3. Upload all files in this folder to the repository root: app.py, requirements.txt, render.yaml, README.txt, README_RENDER.txt.
4. Create/sign in to Render: https://render.com
5. In Render choose New + > Web Service. Connect GitHub and select the ai-media-cleaner repository.
6. Select the Free instance plan if offered, then create the web service. The included render.yaml sets the build and start commands.
7. Wait for the deployment to finish. Render will show a public URL ending in onrender.com. Share that URL.

FREE HOSTING LIMITATIONS
- Render free web services sleep after 15 minutes without traffic and can take about a minute to wake up.
- Free instances have limited CPU/RAM and may struggle with long/high-resolution videos.
- The local filesystem is temporary. Uploaded and processed files can be lost when the service restarts or sleeps. Do not treat it as permanent storage.
- The app's video editor uses one fixed mask for every frame and does not preserve audio.
- Files uploaded to the hosted app are sent to the hosting server for processing. Do not upload confidential media.
- Free hosting limits can change; check Render's current docs: https://render.com/docs/free

PERMISSION
Use only on media you own or are authorized to edit. Do not use the app to remove creator/platform attribution.
